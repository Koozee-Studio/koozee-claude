# Koozee for Claude

Create fashion workflows on a free canvas. Batch-generate fashion images and videos.

This repository is a Claude Code plugin. The clone root has `.claude-plugin/plugin.json` and `.mcp.json`.

- Product: [koozee.ai](https://koozee.ai)
- MCP: `https://koozee.ai/business-api/mcp` (`http`)
- License: MIT

## Install

Clone this repository. The clone root is the plugin root.

```bash
git clone https://github.com/Koozee-Studio/koozee-claude.git
```

Install from that folder in Claude Code. The first MCP connection uses OAuth. Calls without login return 401.

Credits match the Koozee canvas. After the canvas changes, open the project URL Koozee returns.
