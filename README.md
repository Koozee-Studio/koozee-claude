# Koozee for Claude

Create fashion images and videos with AI—all in one place.

Koozee is an AI visual marketing tool for fashion retailers, brands, and entrepreneurs. Use it with Claude to create virtual try-ons, on-model lifestyle images, and fashion marketing videos with simple prompts. Let Claude run workflows to generate images and videos in batches, or build your own on Koozee’s visual canvas. From product listings to marketing campaigns, create compelling visuals and make your products stand out.

This repository is a Claude Code plugin. The clone root has `.claude-plugin/plugin.json` and `.mcp.json`.

- Product: [koozee.ai](https://koozee.ai)
- MCP: `https://koozee.ai/business-api/mcp` (`http`)
- License: MIT

## Install

Clone this repository. The clone root is the plugin root.

```bash
git clone https://github.com/Koozee-Studio/koozee-claude.git
```

Install from that folder in Claude Code. The first MCP connection uses OAuth. Calls without login return 401.

Credits match the Koozee canvas. After the canvas changes, open the project URL Koozee returns.
